# Hugo Yu — Personal Website

A personal website for Hugo Yu (于果), built as a standalone static HTML site.

## Deploy with GitHub Pages

This project requires no build step and no dependencies.

1. Upload the contents of this folder to a GitHub repository.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

The entry point is `index.html`.

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static HTTP server.

## Notes

- The current portrait illustration is embedded directly in `index.html`, so there are no required image assets.
- No framework, package manager, or build command is required.
